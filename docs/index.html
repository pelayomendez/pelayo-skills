pelayo-skills

Small units that each do one job, and flows that chain them. Each one labelled by how it starts: always on, when you type it, or when the agent picks it up.

InstallGitHub

Flows

/backlogSnapshot, prune and order a backlog: closes only what a fresh agent confirmed, then ranks the rest by what unblocks most.
/ambient-companionA day-long session that watches your work's event streams, delegates and checks, and brings you only the decisions.
/night-shiftAn unattended overnight run: a decision round, then queue → delegate → verify → review → smoke → merge, and a morning report.

Units

high-level-communicationAlways on. Report like a senior engineer to another: why, what changed, impact, trade-offs, risks, next steps.
charterOne ledger of what the agent may do alone, must ask first, or never, per scope, in your own words.
verify-claimA fresh agent checks another agent's claim, seeing only the claim and its evidence.
delegate · watch · handoffBrief and launch a worker safely, watch a pipeline or MR until it settles, and leave a handoff another session can resume.
snapshot · prune · order-backlogRead a backlog once, propose what can close with evidence, rank the rest by WSJF inside the dependency graph.
reap-procsFinds what is eating the machine after agent sessions, says whose each process is, and stops only what nobody owns.
tidyYou type it. A weekly and monthly tune-up of your agent setup: retro, memory pruning, steering files, skills, hooks.

Install

/plugin marketplace add pelayomendez/pelayo-skills
/plugin install pelayo-skills@pelayomendez-skills

Or npx skills@latest add pelayomendez/pelayo-skills to copy them into a project. Install one way, not both. The always-on instruction installs with a script; details in the README.
