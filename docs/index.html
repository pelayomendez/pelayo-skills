pelayo-skills

The coding agents are the machines; these skills run the line around them, so one person can supervise from on the loop instead of in it. Small units, chained into flows.

InstallGitHub

Flows

You type a flow. Each one chains units in order and stops for you where a decision is yours.

/supportTakes bugs from report to released: qualify, confirm the cause with a fresh agent, pick, fix and review with workers, check in a controlled browser, ship, check again on the test environment, close.
/mr-reviewReviews the open MRs, yours and your teammates', at their current head, and stops for you on each one. Nothing is pushed, merged or posted without your word.
/backlogSnapshot, prune and order a backlog: closes only what a fresh agent confirmed and you approved, then ranks the rest by WSJF inside the dependency graph.
/ambient-companionA day-long session that watches your work's event streams, delegates and checks, and brings you only the decisions.
/night-shiftAn unattended overnight run: a decision round, then queue → delegate → verify → review → smoke → merge, and a morning report.

Units

Small one-job skills the agent reaches for on its own, inside a flow or outside one.

high-level-communicationAlways on. Report like a senior engineer to another: why, what changed, impact, trade-offs, risks, next steps.
charterOne ledger of what the agent may do alone, must ask first, or never, per scope, in your own words.
verify-claimA fresh agent checks another agent's claim, seeing only the claim and its evidence.
delegate · watch · handoffBrief and launch a worker safely, watch a pipeline or MR until it settles, and leave a handoff another session can resume.
qualify · ticket-pick · tracker-moveCheck a bug is ready for an agent, take a ready ticket into work, and move it on the status board.
review-change · ui-checkReview one MR at its current head, read-only; check a fix in a controlled browser, never yours.
snapshot-backlog · prune-backlog · order-backlogRead a backlog once, propose what can close with evidence, rank the rest by WSJF inside the dependency graph.
reap-procsFinds what is eating the machine after agent sessions, says whose each process is, and stops only what nobody owns.
tidyYou type it. A weekly and monthly tune-up of your agent setup: retro, memory pruning, steering files, skills, hooks.

Flow map

An optional pane beside the chat with your flows, their steps in order, and your units, each in one line. Click one to put it in the prompt; it never runs anything on its own. The skills stay plain markdown, so it reads any folder of them.

support    Takes bugs from report to released
  1. qualify   2. verify-claim   3. ticket-pick
  4. delegate  5. ui-check       6. watch
  throughout: charter · tracker-move · handoff

Install

/plugin marketplace add pelayomendez/pelayo-skills
/plugin install pelayo-skills@pelayomendez-skills
/plugin install flow-map@pelayomendez-skills   # optional pane

Or npx skills@latest add pelayomendez/pelayo-skills to copy them into a project. Install one way, not both. The always-on instruction installs with a script; details in the README.
